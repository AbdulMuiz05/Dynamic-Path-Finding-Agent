Dynamic Path Finding Agent

Overview
Dynamic Path Finding Agent is a Python-based project that demonstrates informed search algorithms in both static and dynamic grid environments.

The project implements:
A* Search
Greedy Best-First Search (GBFS)
Manhattan & Euclidean Heuristics
Real-time visualization
Dynamic obstacle handling with re-planning
Performance metrics comparison
This project was developed for an Artificial Intelligence course to analyze and compare search strategies in different scenarios.

Features:
A* Search (Optimal path guaranteed with admissible heuristic)
Greedy Best-First Search (Fast but not always optimal)
Manhattan and Euclidean heuristic selection
Interactive grid (click to add/remove obstacles)
Random obstacle generation
Dynamic obstacle spawning during execution

Performance metrics:
Nodes expanded
Path cost
Execution time
Re-plan count (dynamic mode)

Color-coded visualization for:
Start node
Goal node
Frontier
Visited nodes
Final path
